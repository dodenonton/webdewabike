## 🚀 Cara Hosting di GitHub Pages

1. Masuk ke folder proyek di terminal:
   ```bash
   cd /Users/user/.gemini/antigravity/scratch/dewa-bike-tour
   ```
2. Inisialisasi dan push ke repositori GitHub Anda:
   ```bash
   git init
   git add .
   git commit -m "Complete multi-page Dewa Bike Tour website"
   git branch -M main
   git remote add origin https://github.com/USERNAME-ANDA/dewa-bike-tour.git
   git push -u origin main
   ```
3. Di dashboard GitHub repositori Anda, klik **Settings** > **Pages** > pilih branch **`main`** folder **`/(root)`** > klik **Save**.
4. Website Anda siap diakses di `https://USERNAME-ANDA.github.io/dewa-bike-tour/`.
